The Pumping Lemma

For Regular Languages — Rabin & Scott, 1959

Formal Statement:
∀L ⊆ Σ*, regular(L) ⟹
∃p ≥ 1, ∀w ∈ L, |w| ≥ p ⟹
∃x, y, z ∈ Σ* such that w = xyz
① |y| ≥ 1   (y is non-empty)
② |xy| ≤ p  (xy fits within p)
③ ∀n ≥ 0, xyⁿz ∈ L  (pumping preserves membership)
🔄
Pigeonhole Principle
A DFA with p states must revisit a state when processing a string of length ≥ p, creating a cycle.
✂️
String Decomposition
The cycle corresponds to substring y. x leads to the cycle, z follows it.
⚡
Contradiction Tool
If pumping y breaks the language rule, the language cannot be regular.
